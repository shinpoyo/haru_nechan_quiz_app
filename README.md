# はるしねーちゃん 〜ねーちゃんの知ったかぶり見破りクイズ〜

ねーちゃん（春野 詩音）は雑学を語るのが大好き。でも、その中には本人も気づいていない**うろ覚え・思い込み（ハルシネーション）**が混ざっている……！？
スマホでこっそり裏取りして、ねーちゃんの話が **「嘘」** か **「ホント」** かを見破るノベル風クイズゲームです。

▶ プレイ：https://shinpoyo.com/haru_nechan_quiz_app/

## 🎮 特徴

- **ノベルゲーム風UI**：スマホ縦画面に最適化。立ち絵＋セリフウィンドウ＋ページ送り
- **心地よいノベルゲーム風SE**：Web Audio API による上質な文字送り音（ソフトマリンバ調）と効果音に統一
- **10種類の表情差分**：ドヤ顔・照れ・ガーン・うるうる・ウインクなど
- **ツッコミ機能**：回答前にねーちゃんを揺さぶってヒントを引き出せる
- **こっそりスマホ検索**：回答後に正誤と解説を表示
- **全700問**：嘘347問／ホント353問、9カテゴリ（通常モード・今日の7問ともに全700問から出題）
- **結果シェア**：絵文字で成績をXに投稿（ネタバレなし）
- **今日の7問**：日付ごとに全員共通の7問に挑戦
- **嘘図鑑**：出会った問題と解説をあとから読み返せる

## 🗂 ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面構成 |
| `style.css` | スタイル |
| `app.js` | ゲーム進行・ページ分割・シェア・図鑑 |
| `sound.js` | 高品位効果音・文字送り音エンジン（Web Audio API） |
| `questions.js` | 問題データ（全700問） |
| `assets/` | 立ち絵（WebP）・OGP画像・アイコン |

## 🚀 ローカルで動かす

静的サイトなので、ローカルサーバーで開くだけで動きます。

```bash
python -m http.server 8000
# http://localhost:8000 を開く
```

> `file://` で直接開くとボイスの読み込みが制限される場合があります。
