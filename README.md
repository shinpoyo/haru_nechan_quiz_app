# はるしねーちゃん 〜お姉ちゃんの知ったかぶり見破りクイズ〜

姉がハルシネーション（もっともらしい知ったかぶりの嘘）っぽいことをずっと言うクイズゲームアプリです。  
お姉ちゃん（春野 詩音）の話が**「ハルシネーション（嘘）」**か**「ホント（嘘のようなガチ雑学）」**かを見破ろう！

## 🎮 特徴

- **ビジュアルノベル風UI**: スマホ（縦画面）＆PC両対応の会話ウィンドウ＆立ち絵表示
- **5種類の表情差分＆フルリアクション**:
  - 見破り成功時: てへぺろ顔（「えへへ、バレちゃった〜？」）
  - 騙された時: ドヤ顔（「ふっふっふ〜、引っかかったな〜！」）
  - ホントを見抜いた時: 満面の笑顔（「ピンポーン！さすが！」）
  - ホントを疑ってしまった時: むーっ顔（「今回は本当なのに〜！」）
- **ツッコミ（揺さぶり）機能**: 回答前にお姉ちゃんにツッコミを入れて動揺を誘えるヒント機能
- **ボイス＆サウンド**: Web Speech APIによるお姉ちゃんボイス読み上げ ＆ Web Audio APIによる効果音
- **ハイブリッド出題**: 厳選30問の収録データ ＋ Gemini APIキー設定による無限リアルタイム問題生成

## 🚀 遊び方

静的Webサイト（HTML/CSS/JS）として動作するため、GitHub Pages等にデプロイするだけでどこからでもブラウザで遊べます。

1. リポジトリをクローンまたはダウンロード
2. `index.html` をブラウザで直接開く、またはローカルサーバー（Live Serverや `python -m http.server 8000` など）で起動
