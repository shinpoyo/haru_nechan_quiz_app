# 春野詩音（はるしねーちゃん）キャラクター設定 & 問題作成ガイドライン

本プロジェクトにおけるクイズ問題（`questions.js`）を作成・追加する際の絶対厳守ルールです。

---

## 🌸 1. キャラクター基本設定

- **名前**: 春野 詩音（はるの しおん）
- **愛称**: ねーちゃん
- **一人称**: **「ねーちゃん」** または **「私」**
  > [!CAUTION]
  > **「お姉ちゃん」は絶対に使わないこと！**（過去に表記揺れ・読み間違いで不整合を起こしたため、「ねーちゃん」に統一されています）
- **性格**:
  - 好奇心旺盛で雑学を語るのが大好き。
  - 基本的に自信満々でドヤ顔して話してくるが、実はうろ覚えや思い込みが多い。
  - 嘘を見破られると照れたり、悔しがったり、あたふたする（素直で憎めない）。

---

## 🔒 2. プレイヤーとの関係性（超重要ルール）

> [!IMPORTANT]
> **関係性はあえて謎であり、プレイヤーそれぞれの想像に委ねられています。**
> 決まっているのは **「ねーちゃんが好きな誰か（あなた）」** ということのみです。

- **禁止事項**:
  - プレイヤーを **「弟」「妹」** と呼んだり、兄妹・姉弟関係だと決めつける表現は **絶対禁止**。
  - 同様に「後輩」「先輩」「幼馴染」などの関係性を固定するラベリングも行わないこと。
- **推奨する接し方**:
  - 大好きな相手に「ねえねえ、知ってる？」「あのね！」と嬉しそうに語りかける。
  - 「さすが自慢の〜」「いつも話を聞いてくれてありがとう♪」など、親愛の情を自然に示す。

---

## 🚨 3. 嘘（ハルシネーション）の性質

> [!NOTE]
> ねーちゃんは **悪意や意図を持って嘘をついているわけではありません**。
> 「本人は100%本当だと思い込んで、嬉々として話している」状態です。

- **良い嘘の例**:
  - もっともらしい由来や俗説を真に受けている（例：「シュークリームのシューは昔キャベツを入れてたから」など）
  - 単語の響きや一部分だけ合っていて、結論がとんでもなくズレている。
  - 聞いた人が一瞬「へぇ〜！そうなんだ！」と騙されそうになる絶妙なライン。
- **NGな嘘の例**:
  - 意図的にプレイヤーをだまそうとする悪だくみ口調。
  - 誰が見ても一瞬で嘘だとわかる荒唐無稽すぎるネタ。

## 🗂️ 4. カテゴリ一覧（全9ジャンル・絵文字必須）

問題を作成する際は、必ず以下の9つのいずれかをそのまま指定してください。

1. `🐾 いきもの雑学`
2. `🍔 食べ物・グルメ`
3. `🌌 宇宙・科学`
4. `💻 IT・テクノロジー`
5. `🏛️ 歴史・偉人`
6. `🎨 言葉・文化`
7. `🎵 エンタメ・日常`
8. `🏥 カラダ・健康`
9. `🗾 日本・地理`

## 😊 5. 表情差分リスト

立ち絵スプライト（`haru_<expr>.webp`）に対応する表情名です。

| 表情名 | 特徴・使い所 |
|---|---|
| `normal` | 基本立ち絵・出題時 |
| `doya` | 自信満々・得意気（ホントの出題やヒント時） |
| `happy` | 笑顔・喜んでいる時 |
| `shy` | 照れ・赤面（嘘を見破られて恥ずかしがっている時） |
| `confused` | 困り顔・首をかしげる（ツッコミに対して「あれ？」となる時） |
| `shock` | ガーン！とショックを受けている時 |
| `cry` | 泣き顔・「うわぁ〜ん！」と悔しがる時 |
| `pout` | むすっと拗ねる・ほっぺを膨らませる |
| `wink` | ウインク・お茶目な表情 |
| `tehe` | てへぺろ・おどけた表情 |
