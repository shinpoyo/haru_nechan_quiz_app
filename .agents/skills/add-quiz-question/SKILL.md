# クイズ問題追加スキル（はるしねーちゃん専用）

本スキルは、「はるしねーちゃん（春野詩音）」の世界観とキャラクター設定を厳格に維持しながら、新しい雑学問題（ホント雑学 / 嘘ハルシネーション雑学）を安全に `questions.js` に追加するための標準手順書です。

---

## ⚠️ 絶対厳守ルール（作成前に必ず確認）

詳細な設定は [character_guidelines.md](./references/character_guidelines.md) を参照すること。

1. **関係性はあえて謎**
   - プレイヤーを「弟」「妹」と呼ぶこと、兄妹・姉弟関係だと決めつけるセリフは **一切禁止**。
   - 「ねーちゃんが好きな誰か（あなた）」としての親愛の情を表現する。
2. **一人称は「私」**
   - 春野詩音の一人称は「私」に統一。「お姉ちゃん」や「ねーちゃん」を一人称として自称することは **使用禁止**（「ねーちゃん」はプレイヤー側からの呼び名・愛称）。
3. **悪意のない嘘（ハルシネーション）**
   - わざと騙そうとする嘘ではなく、「本人は100%本当だと信じ込んでいるうろ覚え・勘違い」にする。
4. **9つの統一絵文字カテゴリから選択**
   - `🐾 いきもの雑学`, `🍔 食べ物・グルメ`, `🌌 宇宙・科学`, `💻 IT・テクノロジー`, `🏛️ 歴史・偉人`, `🎨 言葉・文化`, `🎵 エンタメ・日常`, `🏥 カラダ・健康`, `🗾 日本・地理`

---

## 🛠️ 追加手順

### ステップ 1: 問題データの作成

問題データは以下のJSON形式（単一オブジェクト、または複数問の配列）で準備します。

```json
[
  {
    "category": "🐾 いきもの雑学",
    "isHallucination": false,
    "statement": "ねえ知ってる？ フラミンゴってね、実はオスもメスも喉の奥から『赤いミルク』を出して赤ちゃんを育てるんだよ！",
    "hint": "えっ、本当だよ！？ 血液じゃないよ、母乳みたいに栄養たっぷりの特別な液体なんだから！",
    "hintExpr": "doya",
    "reaction": "えへへ〜！ スマホで調べても本当って出たでしょ？ オスもミルクを出せるなんてすごいよね♪",
    "reactionExpr": "happy",
    "pointTag": "ガチ雑学：オスもメスも素嚢乳を分泌する",
    "explanation": "【ホント！】フラミンゴは素嚢（そのう）の内壁から『フラミンゴミルク』と呼ばれる赤い液体を分泌し、オス・メス両親が口移しでヒナに与えて育てます。"
  }
]
```

※ `id` フィールドはスクリプト実行時に自動で最新連番（`q101`, `q102`...）が採番されるため省略可能です。

### ステップ 2: スクリプトによる自動追加

準備したJSONファイルを指定して、スクリプトを実行します。

```bash
# JSONファイルから一括追加する場合
node .agents/skills/add-quiz-question/scripts/add_question.js path/to/questions.json

# 1問を直接追加する場合
node .agents/skills/add-quiz-question/scripts/add_question.js --single '{"category":"...","isHallucination":true,...}'
```

スクリプトは以下を自動で行います：
- 最新のID（`q101` 等）を自動採番
- 禁止ワード（弟、妹、お姉ちゃん）の自動検出とガード
- `questions.js` の末尾への安全な追記

### ステップ 3: バリデーション実行

問題追加後、必ずバリデーションスクリプトを実行して整合性を確認します。

```bash
node .agents/skills/add-quiz-question/scripts/validate_questions.js
```

チェック項目：
- IDの連番重複チェック
- 必須フィールドの欠落チェック
- 9カテゴリの正確性
- 構文エラーの有無
- 嘘 / ホント の比率バランス集計

### ステップ 4: 動作確認 & コミット

1. `git diff questions.js` で追加内容を確認
2. コミットしてプッシュ
   ```bash
   git add questions.js
   git commit -m "feat: add new quiz questions"
   git push origin main
   ```
